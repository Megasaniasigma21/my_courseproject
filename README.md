# Bochkino

Предварительная Android-версия онлайн-кинотеатра на Kotlin. Интерфейс выполнен в тёмной теме с красным акцентом; каталог, поиск, страницы видео и плеер работают на устройстве. Сохранена Activity-структура исходной заготовки, переходы между экранами оформлены через Android Activity.

## Запуск

Открой проект в Android Studio и запусти конфигурацию `app`. При первом запуске создай локальный аккаунт, затем войди. Два коротких видео уже включены в приложение, поэтому каталог и просмотр доступны без отдельного сервера.

## Подключение REST API

Тестовый Python-сервер находится отдельно: `C:\BochkinoVideoServer`. Запусти `START_SERVER.bat`, затем открой приложение на телефоне, подключённом к той же Wi-Fi сети, что и компьютер. Сервер отдаёт каталог и видео из его папки `videos`; для перемотки поддерживаются HTTP Range-запросы. Python 3.13 уже включён в папку сервера, пакеты pip не нужны.

Базовый URL сервера задаётся свойством `bochkinoApiBaseUrl` в `gradle.properties` (сейчас `http://10.246.64.99:8000/api/`). Если IPv4 компьютера изменился, обнови адрес в этом свойстве и пересобери приложение. Для локального тестового потока разрешён HTTP. При ошибке сети приложение продолжает показывать встроенный локальный каталог.

Для другого REST API приложение запрашивает `GET /films` и `GET /films/{id}`. Ответы — JSON-массив и JSON-объект соответственно с полями из `FilmDto` (`id`, `title`, `description`, `year`, `genre`, `duration`, `rating`, `posterUrl`, `videoUrl`, `creator`, `license`, `sourceUrl`).
