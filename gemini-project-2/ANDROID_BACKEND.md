# Android и сервер

1. Запустите `START_BACKEND.bat` из этой папки и оставьте сервер работающим.
2. В Android Studio откройте `D:\My_corseproject`, выполните Gradle Sync и переустановите приложение.
3. Адрес в `D:\My_corseproject\gradle.properties`: `bochkinoApiBaseUrl=http://10.0.2.2:8000/api/`.
4. На компьютере проверьте `http://127.0.0.1:8000/health`, в браузере эмулятора — `http://10.0.2.2:8000/health`. Оба должны вернуть `{"status":"ok"}`.

`10.0.2.2` — адрес компьютера из стандартного Android Emulator. Для физического телефона задайте актуальный IPv4 компьютера в той же сети и пересоберите приложение. `0.0.0.0` — адрес прослушивания сервера, его нельзя использовать как адрес API в приложении.

## Пользователи

Регистрация и вход выполняются через `/api/auth/register` и `/api/auth/login`. Пользователи и сессии находятся только в серверной SQLite `data/cinema.db`:

- `users.password_hash`: PBKDF2-HMAC-SHA256, 600000 итераций, случайная соль для каждого пароля;
- имя и почта: шифрование Fernet с проверкой целостности;
- поиск почты: HMAC-SHA256 вместо открытого адреса;
- `auth_sessions`: SHA256 токена и срок действия 24 часа; выход отзывает токен.

Ключ профилей автоматически создаётся в `data/profile.key` вне базы. Сохраните его вместе с резервной копией в защищённом месте: без него расшифровать профили нельзя. Для отдельного хранения задайте серверную переменную `PROFILE_ENCRYPTION_KEY` (ключ Fernet). Ключ не включается в APK.

Приложение держит текущий профиль и токен только в оперативной памяти. После завершения процесса вход требуется повторить. Старая локальная `users.db`, прежние настройки профиля и локальные аватары очищаются при запуске экрана входа. Старые локальные аккаунты нужно зарегистрировать заново на сервере. Загрузка аватаров убрана, так как ранее фото сохранялись на телефоне. Резервная копия прежних исходников: `integration-staging/android-before-server-auth`.

## Кино

Каталог и карточки загружаются через `/api/films` и `/api/films/{id}` из таблицы `movies` той же SQLite. Встроенный `assets/catalog.json` удалён из Android-проекта. Медиа раздаются из `media`; ссылки на них хранятся в БД. Для добавления фильмов используйте `manage_db.py`.

Локальный HTTP предназначен для разработки; при размещении сервера используйте HTTPS.
